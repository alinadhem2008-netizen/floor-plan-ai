# مخطط — مولّد المخططات المعمارية بالذكاء الاصطناعي

## شنو بالملف؟
مشروع Next.js كامل وجاهز. حالياً يستخدم صورة وهمية (placeholder) بدل استدعاء حقيقي لـ AI توليد الصور.

## طريقة التشغيل (خطوة خطوة)

### 1. تأكد عندك Node.js
نزّل من nodejs.org (اختار النسخة LTS)

### 2. فك ضغط الملف
فك الـ ZIP بأي مكان، افتحه بـ VS Code

### 3. ثبّت الحزم
افتح Terminal داخل VS Code ونفّذ:
```
npm install
```

### 4. شغّل المشروع محلياً
```
npm run dev
```
افتح المتصفح على: http://localhost:3000

### 5. انشره مجاناً
- ارفع المجلد على GitHub (repository جديد)
- روح لـ vercel.com → سجل دخول بحساب GitHub
- Add New Project → اختر الـ repo → Deploy
- بعد دقيقة رح يعطيك رابط شغال: `اسم-مشروعك.vercel.app`

## هيكلية الملفات
```
app/
  layout.tsx      → الإطار العام (خط، RTL)
  page.tsx         → الصفحة الرئيسية (يجمع كل الأقسام)
  globals.css      → Tailwind + إعداد الخط
components/
  Header.tsx
  Footer.tsx
  Hero.tsx         → قسم الترحيب
  GeneratorForm.tsx → نموذج إدخال الأبعاد
  LoadingState.tsx → أنيميشن التحميل
  ResultDisplay.tsx → عرض النتيجة
lib/
  generatePrompt.ts → يبني الـ prompt المخفي (قواعد المنور المركزي)
  mockApi.ts        → محاكاة استدعاء AI (وهمية حالياً)
public/
  mock-floor-plan.png → صورة تجريبية تظهر كنتيجة
```

## الخطوة الجاية (مهم)
الملف `lib/mockApi.ts` حالياً **وهمي** — يرجع نفس الصورة كل مرة بعد انتظار 3 ثواني.
لتفعيل توليد حقيقي:
1. تحتاج API key من مزود توليد صور (مثل OpenAI DALL-E أو Stable Diffusion عبر Replicate)
2. أنشئ ملف `app/api/generate/route.ts` (Next.js API Route) يستقبل الطلب من الفرونت اند ويرسله للـ AI — **المفتاح السري يبقى بالسيرفر فقط، ما يظهر بالمتصفح أبداً**
3. بدّل `lib/mockApi.ts` باستدعاء `fetch('/api/generate', ...)` بدل الـ setTimeout الوهمي

⚠️ **تنبيه:** استدعاءات AI توليد الصور مو مجانية غالباً (تسعير حسب الاستخدام). هذا الجزء الوحيد اللي ممكن يكلف فلوس بالمشروع.

## ملاحظة معمارية
المخططات الناتجة استرشادية فقط. أي بناء فعلي يحتاج مراجعة مهندس معماري مرخّص للتأكد من الجدران الحاملة والتمديدات وأكواد البناء المحلية.
